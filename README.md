# Pflegia Job Scraper

A scraper that collects job listings automatically and delivers the results to Google Drive. It has a Telegram interface.

> The source code of this project is private. This page describes what it does and how it is run.

## What it does
- Collects job listings with a **Selenium**-based scraper.
- Runs on a **schedule**, so listings stay up to date without manual work.
- Publishes the results to **Google Drive**.
- Has a Telegram interface.

## How it is run
- Runs on a Linux server with scheduled jobs.
- Delivered and handed over with project documentation.

Built at Arika (2024 - 2026) as one of five production services I delivered and handed over.
